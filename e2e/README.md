# Сквозная проверка в браузере

`run.sh` поднимает локальную копию Supabase и проходит приложение в Chromium от лица всех трёх пользователей:
вход, списки, все переходы статусов, возврат на доработку с комментарием, CRUD объектов и задач,
прямые ссылки на чужие задачи, «устаревшую» кнопку в двух окнах, выход.

Что настоящее, а что заглушка:
- **Настоящее:** Postgres с теми же миграциями и сидами, PostgREST (тот же сервер, что отвечает
  за `/rest/v1` в Supabase), supabase-js во фронте. Все права проверяет база, как в проде.
- **Заглушка:** `gateway.mjs` вместо Supabase Auth — выдаёт такие же JWT (`sub`, `role: authenticated`),
  пароль у всех `Demo12345!`. Регистрация отвечает «Signups not allowed», как при выключенном signup.

```bash
PGHOST=localhost PGUSER=postgres ./e2e/run.sh
```

Скриншоты ключевых экранов сохраняются в `e2e/screenshots/`.
